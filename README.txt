はたらくナビすぐワーク LP 完成データ
====================================

【公開方法】
このフォルダ内の index.html / privacy.html / assets フォルダを、サーバーの公開フォルダへそのままアップロードしてください。

【LINE URLの設定】
1. assets/js/config.js をテキストエディタで開く
2. LINE_URL: "" のダブルクォーテーション内へ公式LINE URLを入力
   例: LINE_URL: "https://lin.ee/XXXXXXXX"
3. 保存してアップロード

LINE URLが未設定の場合、LINEボタンを押すと設定案内ダイアログが表示されます。
電話ボタン（092-600-3558）は設定済みです。
