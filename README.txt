GitHub Pages公開方法
1. ZIPを展開します。
2. 中身（index.html / privacy.html / assets）をリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branch → main / root を選択します。

LINE URL設定
assets/js/config.js の LINE_URL に公式LINE URLを入力してください。

公開前の確認
・有料職業紹介事業の許可番号など、必要な法定表示を正式情報へ差し替えてください。
・求人条件、生活支援金、即日入寮等の表現は実際の適用条件に合わせてください。
